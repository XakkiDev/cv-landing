# PaperScroll — прототип

Самостоятельный DOM-компонент для прокручиваемого свитка. Исходное содержимое остаётся HTML: ссылки, выделение, клавиатура и чтение экранными программами работают на оригинале. Края создаются из `aria-hidden` и `inert` копий содержимого, нарезанных на полосы и сжатых по цилиндрической кривой. Прокрутка синхронизирует эти полосы с документом.

Это **визуальная аппроксимация**, а не трёхмерная физическая модель намотки. Радиус рулонов оценивается по длине и толщине бумаги, но края нарисованы CSS-полосами. На их границах возможны искажения; настоящий объём торцевых витков и непрерывная геометрия бумаги не реализованы. До публикации отдельной библиотеки необходимы проверка на устройствах, производительность, API, визуальные тесты и доработка модели.

## Использование

Подключить `dist/paper-scroll.css` и импортировать `PaperScroll` из `dist/paper-scroll.js`. Элемент должен содержать один основной контейнер текста (`.paper-inner` или первый дочерний элемент), а обёртке, созданной классом, следует задать размер через CSS.

```js
const scroll = new PaperScroll(document.querySelector('#document'), {
  curlHeight: 62,       // высота видимой части каждого края, CSS px
  segments: 6,          // число полос, 2–32
  coreRadius: 18,       // радиус основы свитка, CSS px
  paperThickness: .18,  // толщина листа в модели, CSS px
  paperColor: '#eee3ca',
  aging: .34,           // 0–1, интенсивность старения; оформляется CSS пользователя
  textureUrl: '',       // необязательный URL текстуры
  shader: true,         // необязательная текстура WebGPU
});

scroll.goTo(document.querySelector('#chapter'));
scroll.destroy();
```

Компонент создаёт декоративные копии во время инициализации. Если содержимое меняется после создания экземпляра, экземпляр следует пересоздать. Ссылки активны только на оригинале, края не перехватывают нажатия. Независимые экземпляры возможны при отдельных контейнерах. Модуль шейдера необходимо размещать рядом с `paper-scroll.js`; при отсутствии WebGPU или сбое используется CSS/указанная текстура.

`src/paper-shader.js` применяет компонент `Paper` из пакета `shaders` для создания небольшой текстуры. Сборка: `npm ci && npm run build`. В текущем тестовом браузере WebGPU недоступен; визуальный результат шейдера на аппаратном GPU требуется проверить отдельно. Интенсивность старения и цвет — параметры прототипа, а не физическая модель материала.

Открытие, закрытие, анимация первого входа, навигация и нажатие на фон принадлежат приложению (`dist/app.js`), а не классу. Их можно заменить при создании другой сцены с несколькими свитками.
