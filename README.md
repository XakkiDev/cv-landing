# Служилая грамота

Статический лендинг-резюме. Трёхмерный свиток — экспериментальная версия, не готовая к выпуску; подробности и ограничения — в [SCROLL_3D_WIP.md](SCROLL_3D_WIP.md).

## Локальный запуск

```sh
npm ci
npm run build
python3 -m http.server --directory dist 8000
```

Открыть `http://localhost:8000/`. На устройствах без WebGL2 включается предыдущая HTML-версия. Состояние свитка хранится в `localStorage` текущего браузера.

## Проверки

```sh
node --test tests/*.test.js
npx playwright install chromium
node scripts/check-webgl.mjs
```

Последняя команда запускает изолированный Chromium с программным WebGL через SwiftShader, проверяет сценарий открытия, прокрутки, перезагрузки и закрытия и сохраняет кадры, видео и диагностический журнал в `test-results/`. Для настройки Chromium используются пониженные гарантии безопасности SwiftShader: тест предназначен только для локального доверенного проекта. Результат не отражает производительность реального GPU.

GitHub Actions выполняет те же проверки на каждом push и pull request, а также вручную. Артефакт `webgl-scroll-*` сохраняется семь дней, в том числе при ошибке. Успешный тест WebGL ещё не означает, что 3D-свиток выглядит корректно: кадры и видео необходимо просмотреть.
